# Booking.com - Web Application for Hotel Booking

## Описание проекта
Веб-приложение для поиска и бронирования объектов размещения (отелей, апартаментов, хостелов).

## Функциональность
- Поиск жилья по параметрам (город, даты, количество гостей, цена)
- Детальная информация об объектах
- Онлайн-бронирование
- Личный кабинет пользователя
- Панель управления для владельцев

## Технологии
- Frontend: HTML5, CSS3, JavaScript
- Backend: Python (Flask/Django)
- Database: PostgreSQL
- Maps: Яндекс.Карты / Google Maps

## Установка
1. Clone repository
2. Install dependencies: `pip install -r requirements.txt`
3. Run: `python app.py`
